# WV Food Insecurity Analysis 🟦🟨
This project looks at data of the food insecurity percent in all 55 of WV's counties from 2023. This was made to apply my learned Data Analysis skills from GWC.

## Installation
To run and view this project, you need to:
- Download and install Python from:
``` bash
https://www.python.org/downloads/
```
Make sure to check **"ADD PYTHON TO PATH"** during installation.
- Download or clone this repository with:
```bash
git clone https://github.com/yaaAfrehb/WV-Food-Insecurity.git
```
- Install required packages using:
``` bash
pip install -r requirements.txt
```
- Run it:
  ```bash
  foodcrisis.py
  ```
